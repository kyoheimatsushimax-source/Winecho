# ワイン帖

ワインを体系的に学び、飲んだ一本を記録するPWAです。

## できること

- **まなぶ**：全6章・19レッスン。読みもの（しくみと理由つき）のあとにクイズ。修了するたびに、ぶどうの房が一粒ずつ色づきます。
- **今日の5問**：学んだ範囲から出題。間違えた問題が優先されます。
- **品種図鑑**：18品種の典型的な味わい・香り・産地。ログに残した品種にスタンプが付きます。
- **ログ**：名前、種類、評価、産地、品種、味わい（甘み・酸味・渋み・ボディ）、香り、価格、店、メモ、ラベル写真。品種の典型と自分の感じ方を比べられます。
- **きろく**：段位、称号、内訳、好みの傾向と「次に試したい品種」。データの書き出し・復元。

## ファイル構成（すべて同じ階層。サブフォルダなし）

```
index.html
manifest.json
sw.js
icon-192.png
icon-512.png
icon-maskable-512.png
apple-touch-icon.png
README.md
```

アイコンをサブフォルダに入れていないので、GitHubの画面へ全ファイルをまとめてドラッグ＆ドロップするだけで反映されます。

## GitHub Pages で公開する

1. 新しいリポジトリを作る（例：`winecho`）。
2. 「Add file → Upload files」で、上の8ファイルをすべて選んでアップロードし、Commit。
3. Settings → Pages → Branch を `main` / `(root)` にして Save。
4. 数分後、`https://（アカウント名）.github.io/winecho/` を iPhone の Safari で開く。
5. 共有ボタン →「ホーム画面に追加」。

## 更新するとき

ファイルを差し替えたら、`sw.js` の `CACHE = 'winecho-v1'` の番号を上げてください。上げないと古い画面が出続けることがあります。

## データについて

- 記録は端末の中（localStorage、写真は IndexedDB）にだけ保存され、外部には送信されません。
- Safari の履歴とWebサイトデータを消すと記録も消えます。「きろく」→「ファイルに書き出す」で控えを取ってください。
- アプリを更新（ファイル差し替え）しても記録は残ります。

## 学習内容の出典について

内容は一般的なワイン教本で共通して扱われる範囲です。日本の制度（日本ワインの表示ルール、地理的表示）は国税庁の公開情報に沿っています。法令や格付けは改定されることがあります。
