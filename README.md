# ワイン帖

ワインを体系的に学び、飲んだ一本を記録するPWAです。

## できること

- **まなぶ**：全6章・19レッスン。読みもの（しくみと理由つき）のあとにクイズ。修了するたびに、ぶどうの房が一粒ずつ色づきます。
- **上級ドリル**（v2）：ソムリエ試験レベルの4択、全89問。章ごとに最大12問を出題し、8割で突破。
- **模擬試験**（v2）：上級問題から20問、7割で合格。解説は最後にまとめて表示。本試験の出題形式・範囲を再現したものではありません（日本酒・酒類全般・サービス実技などは未収録）。
- **今日の5問**：基礎／上級を切り替え可能。間違えた問題が優先されます。
- **地図**（v2）：世界地図から12か国を選び、66産地の位置・主な品種・特徴を表示。ログの「国」「産地」が一致した記録は、その産地に並びます。
- **品種図鑑**：18品種の典型的な味わい・香り・産地。ログに残した品種にスタンプが付きます。
- **ログ**：名前、種類、評価、産地、品種、味わい（甘み・酸味・渋み・ボディ）、香り、価格、店、メモ、ラベル写真。品種の典型と自分の感じ方を比べられます。
- **きろく**：段位、称号、内訳、好みの傾向と「次に試したい品種」。データの書き出し・復元。

## ファイル構成（すべて同じ階層。サブフォルダなし）

```
index.html
manifest.json
sw.js
icon-192.png
icon-512.png
icon-maskable-512.png
apple-touch-icon.png
README.md
```

アイコンをサブフォルダに入れていないので、GitHubの画面へ全ファイルをまとめてドラッグ＆ドロップするだけで反映されます。

## GitHub Pages で公開する

1. 新しいリポジトリを作る（例：`winecho`）。
2. 「Add file → Upload files」で、上の8ファイルをすべて選んでアップロードし、Commit。
3. Settings → Pages → Branch を `main` / `(root)` にして Save。
4. 数分後、`https://（アカウント名）.github.io/winecho/` を iPhone の Safari で開く。
5. 共有ボタン →「ホーム画面に追加」。

## 更新するとき

ファイルを差し替えたら、`sw.js` の `CACHE = 'winecho-v2'` の番号を上げてください。上げないと古い画面が出続けることがあります。

## データについて

- 記録は端末の中（localStorage、写真は IndexedDB）にだけ保存され、外部には送信されません。
- Safari の履歴とWebサイトデータを消すと記録も消えます。「きろく」→「ファイルに書き出す」で控えを取ってください。
- アプリを更新（ファイル差し替え）しても記録は残ります。

## 地図データ

国境線は Natural Earth（パブリックドメイン）を world-atlas 経由で加工し、index.html に埋め込んでいます。通信なしで表示できます。産地の点は代表的な町の位置で、産地の範囲を示すものではありません。

## 学習内容の出典について

内容は一般的なワイン教本で共通して扱われる範囲です。日本の制度（日本ワインの表示ルール、地理的表示）は国税庁の公開情報に沿っています。上級問題のうち、サン・テミリオン2022年格付け、リオハの熟成規定、OIV登録年、日本ワインの表示割合は公開情報で照合済みです。それ以外は教本で定説とされる内容に基づきます。法令や格付けは改定されることがあります。
